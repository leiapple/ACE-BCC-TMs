# POTCAR

VASP POTCAR files are distributed under the VASP license and are therefore not included in this repository.

The calculations use the PBE PAW potentials (PAW_PBE) of the original GAP-2020 database:

| Element | POTCAR |
|---|---|
| V  | V_sv  |
| Nb | Nb_sv |
| Ta | Ta_pv |
| Mo | Mo_sv |
| W  | W_sv  |

Copy the corresponding POTCAR from your VASP installation into this folder before running the calculations.
